A dip-buy trend bot that trades Coinbase Wrapped BTC (cbBTC) against USDC minute by minute on on-chain prices: an EMA(40/120) trend filter gates dip entries 0.8% under the 120-bar running high, with a +3% take-profit, a 2.5% trailing stop, a 3% hard stop and a 3% crash brake, and a 60-bar cooldown after a stop-loss. Dev window: +$27.27 net PnL, 2 trades, max drawdown 0.95%.

## Run it

```sh
python3 -P -s main.py
```
